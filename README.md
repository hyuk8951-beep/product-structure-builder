# 제품 구조도 생성기 (Product Structure Builder)

웹 브라우저에서 쉽고 빠르게 계층형 제품 구조도(Tree Diagram)를 만들고 이미지로 내보낼 수 있는 도구입니다.

## 주요 기능
* **직관적인 노드 관리**: 하위 항목 및 동급 항목을 버튼 클릭으로 쉽게 추가/삭제할 수 있습니다.
* **자동 선 연결**: 항목이 추가됨에 따라 계층 구조를 나타내는 직각 선(Tree Line)이 자동으로 렌더링됩니다.
* **색상 커스터마이징**: 특정 단계(Level)의 전체 색상을 일괄 변경하거나, 원하는 단일 노드의 색상만 개별적으로 지정할 수 있습니다.
* **간격 조절**: 노드 간의 전체적인 상하좌우 간격을 슬라이더로 조절할 수 있습니다.
* **자동 저장**: 브라우저의 로컬 스토리지(Local Storage)를 사용하여 작업 중인 상태가 자동으로 유지됩니다.
* **이미지 다운로드**: 완성된 구조도를 배경이 포함된 PNG 이미지 파일로 즉시 다운로드할 수 있습니다.

## 실행 방법
별도의 설치가 필요 없는 순수 HTML/CSS/JS 기반의 정적 웹 페이지입니다.

1. `index.html` 파일을 크롬(Chrome), 엣지(Edge) 등 최신 웹 브라우저로 엽니다.
2. 또는 로컬 웹 서버를 실행하여 접속합니다 (이미지 다운로드 기능의 100% 호환성을 위해 권장).
   ```bash
   python -m http.server 8000
   ```
   이후 브라우저에서 `http://localhost:8000` 으로 접속합니다.

## 기술 스택
* HTML5
* CSS3 (CSS Variables, Flexbox)
* Vanilla JavaScript
* [html2canvas](https://html2canvas.hertzen.com/) (이미지 캡처 라이브러리)
